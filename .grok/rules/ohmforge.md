# Ohmforge project rules (Grok Build)

Grok Build also reads the root `AGENTS.md`; that file is the full guide and wins on any conflict. Short version:

1. Source of truth: `docs/DESIGN_AND_PLAN.md` (never edit it unless Stefan asks). Current tasks: `docs/ROADMAP.md`.
2. Current phase: **P2 (ESP32-C3 MVP) is in progress**; P1 Analog core is complete. P2 so far: ELF and ESP flash image loading (`of-firmware`), the C3 memory map, GPIO/IO MUX, UART0 TX, SYSTIMER with alarms, the interrupt matrix, TIMG0/1 and the watchdogs, and `Esp32c3Engine` (`of-soc-esp32c3`, `AGENTS.md` section 3c), with the blinky firmware in `firmware/` driving an LED end to end and a timer-interrupt firmware; the desktop app (`of-app --features gui`) runs a read-only blink demo from `of-ui` (schematic with a live LED, LED current trace, UART0 output); the C3 hart has no `mie`/`mip` (`HartConfig::mie_mip`); next steps are in the roadmap's "First milestone" list. P1 covers `crates/of-analog`, `of-netlist::spice`, `ohmforge run`, the parts bridge `of_components::analog`, `AnalogEngine` under the `of-core` kernel and the AMS1117 macromodel (design notes in `AGENTS.md` section 3b). Phase one, the RISC-V core (`crates/of-cpu-riscv`, section 3a), is done. New analog features need an analytic test and an ngspice golden circuit (`* ngspice-replace:` for Ohmforge-only syntax), all within 1 %; new analog parts also need datasheet checks through the bridge. Register CPU engines before the analog engine.
3. Rust edition 2024, MSRV 1.95. On Windows, load the Build Tools `vcvars64.bat` environment for that machine first (`AGENTS.md` section 9). Then run `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, the GUI check and the wasm32 check from `AGENTS.md`.
4. Licence: code is AGPL-3.0-or-later, parts data and docs CC-BY-SA-4.0. Dependencies must be AGPL-compatible (the permissive `deny.toml` allow list; no GPL-2.0-only or LGPL); never copy code from QEMU, CircuitJS, SimulIDE or Wokwi. riscv-tests (BSD-3) are built from source, never committed. ngspice is only ever run as an external tool to make golden CSVs (`scripts/gen-ngspice-golden.sh`); never link, vendor or ship it.
5. Git: report changes to Stefan and propose a commit breakdown; **commit only after his approval**. Commits are signed off (`git commit -s`) Conventional Commits. Remote `origin` is https://github.com/sjnorval/Ohmforge; `main` holds the merged P1 work (PR #7) and the blinky milestone (PR #8); current branch `p2-interrupts-timers`. New work goes on feature branches off `main` and reaches it only through pull requests Stefan merges; never push to `main`. Push only when Stefan says so, never force-push, never handle tokens.
6. **Ohmforge** is the final name; crates use the `of-` prefix.
7. Simulation crates stay deterministic (virtual `SimTime`, no wall-clock) and wasm32-compatible.
