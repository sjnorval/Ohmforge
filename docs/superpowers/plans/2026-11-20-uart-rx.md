# UART0 RX FIFO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an instant UART0 RX FIFO on the ESP32-C3 model and attach the serial monitor’s host→device queue so Send delivers bytes into that FIFO.

**Architecture:** `Uart` owns a 128-byte `VecDeque` RX buffer; FIFO reads pop it and `STATUS.RXFIFO_CNT` reflects depth. `Esp32c3::push_uart_rx` is the public inject API. `SerialMonitor` gains `Delivery::Attached`; blink drains `pending_tx` into the SoC each frame.

**Tech Stack:** Rust edition 2024, `of-soc-esp32c3`, `of-instruments`, `of-ui` (gui feature).

**Spec:** `docs/superpowers/specs/2026-11-20-uart-rx-design.md`

## Global Constraints

- Instant RX only — no baud timing, no RX interrupts.
- Max RX depth **128**; overfill **drops oldest**.
- Do not commit without Stefan’s approval; propose Conventional Commits + `Signed-off-by`.
- Load MSVC Build Tools on Windows before cargo (AGENTS.md §9).
- No new deps; keep `of-instruments` free of SoC types.

```rust
fn rx_fifo_cap_drops_oldest() {
    let mut u = Uart::new();
    let mut data = vec![0u8; Uart::RX_CAPACITY + 3];
```

In `uart.rs`:

```rust
use std::collections::VecDeque;

pub const RX_CAPACITY: usize = 128; // or Uart::RX_CAPACITY associated const

pub struct Uart {
    config: [u32; CONFIG_RESET.len()],
    int_raw: u32,
    rx: VecDeque<u8>,
}

impl Uart {
    pub const RX_CAPACITY: usize = 128;

    pub fn new() -> Self {
        Self {
            config: CONFIG_RESET.map(|(_, v)| v),
            int_raw: TXFIFO_EMPTY,
            rx: VecDeque::new(),
        }
    }

    pub fn push_rx(&mut self, bytes: &[u8]) {
        for &b in bytes {
            if self.rx.len() == Self::RX_CAPACITY {
                self.rx.pop_front();
            }
            self.rx.push_back(b);
        }
    }

    pub fn read(&self, off: u32) -> Option<u32> {
        // FIFO needs &mut — change read signature for FIFO only via bus,
        // OR use interior for pop. Prefer making FIFO pop in a separate
        // method called from bus: `uart0.pop_rx() -> u8` and keep read()
        // immutable for other regs.
    }
}
```

**Preferred shape (matches bus mutability):** keep `read` immutable for config; for FIFO, change bus dispatch to:

```rust
map::UART0_BASE if off == uart::reg::FIFO => Some(u32::from(self.uart0.pop_rx())),
map::UART0_BASE => self.uart0.read(off),
```

with:

```rust
pub fn pop_rx(&mut self) -> u8 {
    self.rx.pop_front().unwrap_or(0)
}

fn status(&self) -> u32 {
    (STATUS_IDLE & !0x3ff) | (self.rx.len() as u32 & 0x3ff)
}
```

and `read(STATUS) => Some(self.status())`. Remove the old `FIFO => Some(0)` arm from immutable `read`, or keep it unused.

`Esp32c3::push_uart_rx`:

```rust

    self.bus.uart0.push_rx(bytes);
}
```

```rust
pub(super) fn push_uart_rx(&mut self, bytes: &[u8]) {

        .expect("registered ESP32-C3")
```
