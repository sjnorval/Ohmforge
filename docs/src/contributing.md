# Contributing

See the repository [`CONTRIBUTING.md`](https://github.com/sjnorval/Ohmforge/blob/main/CONTRIBUTING.md)
for DCO sign-off, Conventional Commits, licence rules and the pull-request
checklist.

Validate every `part.toml` under `parts/` with:

```sh
cargo run -p of-cli -- validate-parts parts/
```
