# Roadmap

The live task list is [`docs/ROADMAP.md`](https://github.com/sjnorval/Ohmforge/blob/main/docs/ROADMAP.md).
P2 (ESP32-C3 MVP) is in progress; P0 leftovers continue alongside. P3 adds
official examples, file-based sharing, a breadboard view, the first
compatibility checks, and the first slices of a part creator; P4 adds
MicroPython on the ESP32-C3, wireless fidelity documentation, and a Verilog-A
sidecar.
