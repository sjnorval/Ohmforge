# Ohmforge

Ohmforge is an open-source, true-to-life ESP32 circuit simulator. It runs
unmodified ESP32 firmware against a SPICE-grade analog circuit in one
deterministic simulation.

This mdBook is a skeleton: chapters link into the living docs in the
repository. Guide previews cover your first schematic, official examples and
sharing, compatibility checks, and wireless fidelity. Full user and
part-authoring guides land in phase P6.

- Source of truth for architecture: [`docs/DESIGN_AND_PLAN.md`](https://github.com/sjnorval/Ohmforge/blob/main/docs/DESIGN_AND_PLAN.md)
- Agent and contributor build rules: [`AGENTS.md`](https://github.com/sjnorval/Ohmforge/blob/main/AGENTS.md)
- Desktop app: `cargo run -p of-app --features gui`
