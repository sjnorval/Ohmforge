# Ohmforge Startup Animation Concepts

These are AI-generated concept assets for a potential startup / splash screen animation for the Ohmforge desktop and web apps.

## Preferred direction
Warm neon “digital fire forge” aesthetic combining:
- Cyberpunk neon and glitch
- Matrix-style digital rain (in amber/orange)
- Tesla industrial design language (clean geometry, precise motion, premium materials)

The animation typically:
1. Materialises a holographic Ω logo with diagonal slash
2. Morphs / transitions into the ESP32 board with gold traces and glowing LEDs
3. Locks into the classic social-preview framing (text left, board right)

## Files
- `startup-cyberpunk-matrix-tesla.mp4` — full animation concept
- `startup-still.png` — final-frame still matching the social-preview layout

Large binary video files are not committed by default to keep the repository lean. Download the latest versions from the conversation or regenerate as needed.

## Usage
These can be used as reference for:
- An egui splash screen in `of-app`
- A web loading animation in `of-web`
- GitHub social / README visuals
