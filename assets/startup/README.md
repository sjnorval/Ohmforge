# Ohmforge startup animation

Assets for the Ohmforge desktop and web load screen, in a warm neon “digital fire forge” style (cyberpunk neon and glitch, Matrix-style digital rain in amber/orange, and Tesla-like industrial geometry).

Licence: [CC-BY-SA-4.0](../../parts/LICENSE.md), same as other Ohmforge artwork, parts data and docs.

## Committed files

- [`EILIi.mp4`](EILIi.mp4) — the final animation: 6 seconds, 736×400, social-preview framing (text left, board right). Source concept name: EILIi.
- [`startup-still.png`](startup-still.png) — the last frame of `EILIi.mp4`, same 736×400 size.

These replace an earlier broken `startup-still.jpg` placeholder (103 bytes) that was not a usable image.

## Planned use

This video is planned as the app's load screen. It will be converted to frames and played in the UI; the app will not ship a video decoder. The still can be used as a poster or fallback frame.

## Other concepts

Three other concept videos (`concept-1.mp4`, `concept-2.mp4`, `concept-4.mp4`) are not committed, to keep the repository lean. They will be attached to the pull request that lands this animation (Stefan will drag them into a PR comment).
