# Getting help

Ohmforge is pre-alpha and maintained in spare time. Help is given on a best-effort basis.

## Questions and ideas

Use [GitHub Discussions](https://github.com/sjnorval/Ohmforge/discussions):

- **Q&A** for "how do I...?" questions about building, running or using Ohmforge.
- **Ideas** for features and design thoughts that are not yet concrete enough for an issue.
- **Show and tell** for circuits, parts and firmware you have simulated.

Before asking, check the [README](README.md), the [roadmap](docs/ROADMAP.md) (what is done and what is not yet), [CONTRIBUTING.md](CONTRIBUTING.md) and [`firmware/README.md`](firmware/README.md).

## Bugs, features and parts

Open an [issue](https://github.com/sjnorval/Ohmforge/issues/new/choose) using one of the forms:

- **Bug report** for crashes, wrong behaviour or simulation results that differ from ngspice, a datasheet or hardware.
- **Feature request** for concrete improvements.
- **New part or model** to request a real, orderable part.

## Security

Do not report vulnerabilities in public. See [SECURITY.md](SECURITY.md).

## Conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
